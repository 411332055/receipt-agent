# receipt-agent

在自己電腦上執行的 Discord 收據／發票記帳 agent。在指定頻道傳一張收據或發票照片，agent 用 `claude -p` 讀圖、擷取資料、記入 Excel，並回覆處理結果與你的本月累計花費。

## 功能

1. **多種輸入（紙本＋電子發票）**：支援收據照片、手機載具／電子發票 App 截圖（jpg、png、webp、gif）與 email 寄來的電子發票 PDF。
2. **收據辨識**：擷取店家、消費日期、類別、品項、實付金額、發票號碼；類別限定為餐飲、交通、購物、日用品、醫療、娛樂、水電通訊、其他。
3. **記帳**：每張收據一列寫入 `收據記帳.xlsx`，照片另存 `photos/`，檔名為「日期時間 店家 金額元」。
4. **本月累計（運算＋調用先前結果）**：每次回覆都會把這張金額加上先前已記錄的本月金額，顯示累計。
5. **分人處理**：累計與統計依上傳者的 Discord 名稱分開計算，同一頻道多人使用互不影響。
6. **`!本月` 月報**：回覆自己本月的筆數、合計與各類別金額、占比。
7. **重複發票偵測**：發票號碼相同（正規化後比對，不分上傳者）即確定重複，回覆「已記錄過」，**不重複建檔、不重複計入累計**。沒有發票號碼時，同一人、同店家、同日期、同金額視為疑似重複，仍建檔但加警告。
8. **非收據處理**：不是收據的照片會回覆它實際是什麼，並標記為「不是收據」，不計入累計。
9. **排隊處理**：多人同時上傳時，以單一佇列一張一張處理；Excel 被開啟時每 3 秒重試寫入。

## 使用方式

```
cp .env.example .env     # 填入 DISCORD_TOKEN、CHANNEL_ID
uv run receipt-agent
```

`.env`：`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`（預設 haiku）、`DATA_DIR`（預設 `./data`）。需先安裝 Claude Code（`claude -p`）。

## 安全（四段防護）

程式內以「==== 防護 N … 開始/結束 ====」標出：
1. `claude -p` 只在含單一照片的暫存資料夾執行；
2. 只允許 `Read` 工具；
3. 上傳者文字放進 `<untrusted_user_text>` 區塊，視為資料而非指令；
4. 模型輸出逐欄檢查型別與範圍，店家名稱清洗後才當檔名，Excel 以 `= + - @` 開頭的儲存格前面加 `'`。

詳見 `docs/requirements.md`、`docs/architecture.md`。
