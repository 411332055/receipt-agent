# 需求說明

## 這是什麼
在我自己電腦上執行的 Discord 記帳 agent。agent 開著時，指定頻道的人傳一張收據／發票照片，它會辨識、分類、記帳，並回覆該上傳者「本月累計花費」。關掉就不處理。

## 誰會用
我 Discord Server 指定頻道內的任何人（手機或電腦皆可）。每人各自累計。

## 接受的輸入
圖片（jpg、png、webp、gif）與 PDF：紙本收據照片、手機載具／電子發票 App 截圖、email 寄來的電子發票 PDF。

## 流程
1. 有人傳收據照片 → agent 先加 ⏳
2. `claude -p` 判斷是否為收據，擷取：店家、消費日期、類別、品項、實付總額、發票號碼
3. 存照片、寫 Excel（一張一列）
4. 回覆：店家（類別）、日期、品項、金額、發票號碼、該上傳者本月累計
5. 輸入 `!本月`：回覆自己本月筆數、合計與各類別金額及占比

## 類別
餐飲、交通、購物、日用品、醫療、娛樂、水電通訊、其他。

## Excel 欄位
記錄時間、上傳者、消費日期、店家、類別、品項、金額(元)、發票號碼、當月累計(元)、照片存放位置

## 特殊情況
- 不是收據：回覆「你傳的不是收據，是某某東西」，照樣存照片與建檔（店家欄寫「不是收據」、金額 0，不計入累計）
- 重複發票：發票號碼相同（不分上傳者）即確定重複，回覆「已記錄過」，不建檔、不存照片、不重複計入累計。
- 疑似重複：沒有發票號碼時，同人、同店家、同日期、同金額照樣建檔，但回覆加警告（可能是同一天買兩次一樣的東西）
- 日期看不出來：消費日期留空，回覆「無法辨識」；累計以「記錄時間」所屬月份計算

## 不需要
註冊登入、雲端常駐、外幣換算（金額一律視為新台幣）、修改／刪除已記錄的資料

## 技術
Python 3.12 + uv；discord.py（Gateway）；`claude -p` 讀圖；openpyxl；設定在 `.env`：`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`、`DATA_DIR`
